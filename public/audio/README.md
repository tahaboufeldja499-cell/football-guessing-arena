# موسيقى اللعبة

الملفات هنا تُشغَّل تلقائيًا حسب شاشة اللعبة، وتتناوب بالتسلسل إن وُجد أكثر من ملف للحالة نفسها:

| الحالة | الملفات | المقطع الأصلي |
|---|---|---|
| القائمة والغرفة واختيار اللاعب | `music-menu.mp3` ثم `music-menu-2.mp3` | Green Velvet Stage، ثم Under These Lights |
| المباراة | `music-match.mp3` ثم `music-match-2.mp3` | Before the Whistle، ثم The Architect's Gambit |
| الفوز ونهاية الجولة | `music-win.mp3` | The Weight of Gold |

لتغيير التوزيع: بدّل أسماء الملفات (احتفظ بنفس الأسماء)، أو عدّل القائمة `MUSIC` في `src/lib/sounds.ts` لإضافة مقاطع.
إن فشل تحميل ملف تعود اللعبة تلقائيًا إلى الموسيقى المولَّدة بالكود.

المقاطع مُوحَّدة الصوت (نحو -18 LUFS) ومضغوطة 128kbps. مقدمة الدخول والمؤثرات الصوتية مولَّدة بالكود (`src/lib/audio/synth.ts`).
