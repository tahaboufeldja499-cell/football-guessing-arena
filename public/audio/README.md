# موسيقى حقيقية (اختياري)

اللعبة تولّد الموسيقى والمؤثرات بالكود، فتعمل من أول تشغيل. لاستعمال موسيقى أفضل ضع ملفات mp3 هنا بهذه الأسماء بالضبط وسيستعملها الموقع تلقائيًا بدل الموسيقى المولَّدة:

- `music-menu.mp3`  القائمة والغرفة واختيار اللاعب
- `music-match.mp3` أثناء المباراة
- `music-win.mp3`   الفوز ونهاية الجولة

الشروط: ملفات مرخّصة للاستعمال في مشروعك (مثل Pixabay Music أو Free Music Archive بحسب رخصة كل مقطع، أو مقطع اشتريته)، وبصيغة تتكرر بسلاسة (loop). لا تضع موسيقى محمية بحقوق نشر بلا إذن. مقاطع المقدمة والمؤثرات تبقى مولَّدة.
